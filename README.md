# パネル開け卓

TikTok LIVE / 配信向けの「パネル開け」ボード。
ギフトの数を数えてパネルを1枚ずつめくり、下に隠した画像や動画を出していきます。

**単体HTML 1枚**です。サーバーもインストールも不要で、ブラウザで開けばそのまま使えます。

## 使い方

1. **画像** — 公開用（下に隠す絵／動画）と、パネル（覆う側の絵／動画）をドラッグ＆ドロップ
2. **割り方** — グリッド／中央シェイプ（ハート・桜・雷など12種）／ジグソー／ハニカム／放射／同心円／ダイヤ
3. **フレーム** — ネオン・ゴールド・リボン・もこもこ・きらきら・水玉（色と光り方も選べます）
4. パネルを選んで **必要数** を設定。当たり枠は「当たり枠（金）」で金枠＋発光に
5. **配信モード**へ切り替え → パネルをクリックして選び、下の ＋／− で加算

必要数に届いたパネルが消えて下の絵が出ます。開くたびに中央シェイプと同じ形が降ってきて、
砂時計のように引いていく演出が入ります。全部開くと「コンプリート」表示。

## 配信に載せる

いちばんきれいなのは **OBS のブラウザソース**です。OBS のブラウザソースは
ページの透明部分をそのまま抜いてくれるので、クロマキーは要りません。

1. OBS →「ブラウザ」ソースを追加、この index.html のURL（またはローカルファイル）を指定
2. ツール側で **背景＝透明（OBS用）** を選び、**「盤面だけ」** を押す
3. ソースを右クリック →「対話」で、パネルをクリック／`+` `-` キーで数えられます

透過PNGを公開用画像にすれば、絵の透明部分もそのまま抜けます。

画面共有やウィンドウキャプチャで映す場合は、背景を **クロマキー緑** にして
OBS の「クロマキー」フィルタで抜くか、**全画面** でそのまま映してください。
- 設定はブラウザに自動保存されます（動画も含めて開き直しても残ります）
- 「ファイル ▾ → 設定を書き出す」でJSONを保存すれば、同じ盤面を他の人と共有できます

## ショートカット

| キー | 動作 |
|---|---|
| `+` / `Enter` | 選択中のパネルに加算 |
| `-` | 減算 |
| `1`〜`5` | 加算量の切り替え |
| `⌘Z` / `Ctrl+Z` | 1つ戻す |
| `Esc` | 選択解除 |

## 動作環境

Chrome / Edge / Safari の最新版。スポイト（画面から色を拾う機能）は Chromium 系のみ。
